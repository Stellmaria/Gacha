# Gacha: демо-рулетка в существующем Telegram-боте

Текущий бот **тестовый по назначению, но создан в обычной сети Telegram**. Это подтвердили диагностические GitHub Actions runs, включая [44796501612](https://github.com/Stellmaria/Gacha/actions/runs/44796501612). Никакого отдельного «боевого» бота пока нет, и он для демо не нужен.

## Подготовка

- Уже сохранённый GitHub Actions Secret `GACHA_TEST_BOT_TOKEN` используется для **существующего** бота.
- Защита: все операции с токеном запускаются только вручную; файлы проекта не содержат токена.
- Проверить `getMe`: https://github.com/Stellmaria/Gacha/actions/workflows/telegram-preflight.yml → `existing-test-bot`.

## Демонстрация

1. В **обычном Telegram** (не отдельном Test Server) открой личный чат текущего бота и отправь `/wheel` (без параметров).
2. Открой https://github.com/Stellmaria/Gacha/actions/workflows/telegram-inline-smoke.yml и запусти `Run workflow` на `main`.
3. GitHub-hosted runner обрабатывает **только один свежий приватный чат** с командой /wheel за последние 10 минут. Если есть несколько отправителей, он прекращает выполнение.
4. Бот пришлёт сообщение с inline-кнопкой «Крутить (демо)». Нажми её в течение **80 секунд**.
5. Программа выбирает сервером одну редкость по распределению Classic 25% / Elite 22% / Royal 19% / Epic 16% / Mythic 11% / Eternal 7%, генерирует прозрачную декоративную GIF (с использованием векторного оформления из `assets/roulette/ornate-wheel.svg`), стрелка останавливается на соответствующем секторе. Сначала отправляет анимацию **без названия редкости**, затем спустя 7,5 секунды отдельное сообщение с выпавшей редкостью.

## Ограничения

- Анимация может зацикливаться на стороне Telegram.
- Нет реальных карточек, валюты, попыток, платежей, постоянного сервера, БД, webhook или фонового polling.
- Скрипт безопасно прекращает выполнение, если видит конфликт с webhook/другим poller, неверную авторизацию, неоднозначную цель или неожиданный callback.
- Логи не содержат токен, chat ID, содержимое приватных сообщений или URL с credential.
- GitHub Actions unit tests/renderer PASS не доказывают live доставку до реальной проверки.
- Для настоящих Telegram HTML Widgets на dedicated Test Server нужен отдельный тестовый аккаунт и бот в **другой сети Telegram**. Это не препятствует испытанию inline-кнопки и GIF с текущим ботом.

## Визуальная точность

В репозитории сейчас установлена **векторная реконструкция** колеса по образцу из чата. Шесть оригинальных пользовательских GIF файлов, каждый ~7 MB, в GitHub пока не загружены; поэтому без бинарных файлов бот использует именно SVG-аниматор. Подготовлен прямой приоритет оригиналов по именам в `assets/roulette/original_gifs/`, когда все шесть будут доступны. Не путать эти варианты.

Telegram может начать воспроизведение позже отправки: задержка 7,5 секунды измеряется от ответа Bot API, не от фактического окончания воспроизведения у пользователя. Это снижает риск раннего reveal, но не устраняет его на медленном соединении.
