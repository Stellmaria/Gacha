# Шестисекторный Telegram Widget (тестовая версия)

- Вес каждого сектора: Classic 25%, Elite 22%, Royal 19%, Epic 16%, Mythic 11%, Eternal 7%.
- Автономный HTML, без внешних ресурсов, библиотек, API браузера и запросов в сеть.
- Нажатие вызывает `TelegramWidget.request('spin')`. Демо-результат возвращает тестовый бот, не клиент.
- После `answerWidgetQuery` колесо делает 6 оборотов; `editMessageWidgetData` сохраняет `{i:<0..5>}` для восстановления. После одного тестового вращения кнопка блокируется.
- Никакого реального каталога, карт, кошельков, выплат или бонусных круток здесь нет.
- Отправлять только на выделенном Telegram Test Server через ручной CI. Подтверждения работы на реальных клиентах пока нет.

Ограничения: 32768 UTF-8 байт HTML, 4096 zlib-9. Docs https://core.telegram.org/bots/widgets .
