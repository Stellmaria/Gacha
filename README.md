# Gacha (рабочее название)

Независимый прототип коллекционной гачи для Telegram. Финальное название ещё не выбрано.

## Что уже есть

- Два самостоятельных демонстрационных колеса: **ежедневные редкости карточек** (6 секторов, режим по умолчанию) и **призы** (8 секторов).
- Пропорциональные вероятностям SVG-секторы, плавная анимация с указателем, адаптивная тёмная тема.
- Прозрачный выбор исхода и проверки таблиц вероятностей.
- **Никаких реальных списаний, начислений, Telegram API или подключений к внешним серверам.** Это только UI-демонстрация.

## Ежедневная карточная рулетка — 6 редкостей

Это основной экран будущего бота. Игроку будут начисляться бесплатные крутки в настраиваемые утреннее и вечернее окна. **Количество, время, часовой пояс и перенос остатков пока не утверждены**; для тестов используется условный пример 6+6.

| Редкость | Шанс |
| --- | ---: |
| Classic | 25% |
| Elite | 22% |
| Royal | 19% |
| Epic | 16% |
| Mythic | 11% |
| Eternal | 7% |

## Призовая рулетка — 8 секторов

**Внимание:** это два отдельных набора вероятностей. Связь между ними ещё не утверждена. Ни один исход не меняет баланс игрока.

## Запуск для разработки

Проект не требует зависимостей, npm, Docker или токенов.

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

Либо использовать статический HTTP-сервер. Запускать на production-хостах Velvet не требуется.

## Где хранить токены Telegram

Не вставляйте токен в чат, исходники или переменные `workflow_dispatch`. Для проверки бота используем два GitHub Actions Secrets: `GACHA_BOT_TOKEN` (обычный Telegram) и `GACHA_TEST_BOT_TOKEN` (отдельный Telegram Test Server). [Пошаговая инструкция](docs/BOT_TOKENS.md).

## Тестирование Telegram

Новый fallback для **обычного** Telegram-бота: inline-кнопка, реальная GIF-анимация остановки на одной из шести редкостей, только ручной GitHub Actions smoke без начислений. [Порядок запуска](docs/TELEGRAM_INLINE_FALLBACK.md). Для этого нужен `GACHA_BOT_TOKEN`, а не `GACHA_TEST_BOT_TOKEN`.


GitHub CI проверяет только код и логику, **не работу Telegram-клиента**. Для Widgets нужно отдельное тестовое окружение Telegram и тестовый бот; для публичного бота готовим fallback с inline-кнопкой и анимацией. [План тестирования](docs/TELEGRAM_TEST_PLAN.md).

## Проверки

```bash
node --test
node --check src/app.mjs
node --check src/wheels.mjs
```

Эти же команды выполняет GitHub Actions на `ubuntu-latest`. Проект не содержит секретов и не требует собственных машин.

## Telegram

Планировалась интеграция через Telegram HTML Widgets, но её реальная production-доступность должна быть проверена отдельно до включения. Сейчас UI **не работает внутри Telegram** и не выдаёт награды. Подробнее: [технический контракт](docs/TECHNICAL.md).

Проект не зависит от `Stellmaria/Velvet`, Dominus, Demian или других репозиториев.
