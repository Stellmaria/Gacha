# Velvet Wheel: утверждённый Royal внутри Telegram (без Mini App)

Это ручной визуальный тест в **существующем тестовом боте** обычной сети Telegram. Telegram Bot API [`sendAnimation`](https://core.telegram.org/bots/api#sendanimation) принимает бесшумный H.264 MP4, и Telegram показывает его в сообщении. Это **не HTML Canvas, не Mini App и не переименованный TGS**. Подлинный ролик `wheel/videos/Royal.mp4` (7 277 143 байта, 720×960, 10,4 с) берётся из утверждённого архива #16/#17, проверяется по SHA-256 перед отправкой. Статическая стартовая обложка — подлинный `wheel/source/master.png`.

## Проверка по требованию владелицы

1. Откройте личный диалог с `@velvet_gacha_v1_bot`, отправьте ровно `/royaltest` (не `/wheel`).
2. Вручную запустите [Telegram Royal MP4 — MANUAL TEST](https://github.com/Stellmaria/Gacha/actions/workflows/telegram-royal-mp4-smoke.yml) на `main`. Команда действительна 5 минут, ответ должен прийти в **ровно один** подходящий личный чат; если подходящих пользователей два, тест откажет.
3. Бот отправит оригинальную обложку и единственную кнопку **«Крутить Royal · тест»**. Нажмите в течение 90 секунд. Бот мгновенно ответит на callback и уберёт кнопку до отправки файла.
4. Бот отправит один оригинальный `Royal.mp4` через `sendAnimation` с нейтральной подписью; после номинальных 12 секунд от **подтверждения Telegram API**, отдельный текст **ROYAL**. Других анимаций, иллюстраций или плохой карты-заглушки не будет.

## Честные ограничения

- Тест **фиксирован** на Royal. Это не случайный розыгрыш; не выдаются карты, баланс, валюты и попытки; никаких платежей/Stars/награды.
- Telegram может перекодировать и зациклить `sendAnimation`. Нет гарантии сохранения пиксель-в-пиксель качества браузера. Клиент не сообщает боту о фактическом конце воспроизведения, поэтому текст результата может появиться, когда медленное соединение ещё догружает ролик.
- Этот скрипт не разворачивает постоянный бот, не трогает webhook, не отправляет содержимое переписки в лог; использует GitHub Actions Secret и короткое окно `getUpdates`.
- Запуск требует действий владельца в Telegram и вручную через GitHub Actions/агента. Закрытый CI или HTTP 200 не доказывает реального визуального качества внутри Telegram. Только живой просмотр владельцем.
- При 409 (активный webhook или конкурирующий poller), сомнительном владельце, неверном токене или доставке анимации не подтверждённой Telegram — прекращение без раскрытия результата.
