# Velvet Gacha — полная шестисекторная рулетка в Telegram (визуальный тест)

**Граница:** это отдельный ручной UX-тест, а не постоянный бот, Mini App или запуск платной гачи. Использует `@velvet_gacha_v1_bot` и утверждённые изображения/ролики из `wheel/` (импорт #16/#17), **без пересоздания графики**. Старые Royal/TGS/GIF тесты оставлены без изменений.

## Как устроено

1. В личном Telegram-чате существующему тестовому боту владелица отправляет **ровно `/wheel6`**.
2. Оператор вручную запускает GitHub Actions workflow `telegram-wheel6-smoke.yml` на `main` (входная команда не старше 5 минут, строго один приватный собеседник).
3. Бот загружает утверждённый `wheel/source/master.png` с одной кнопкой **«✦ Крутить колесо»**, показывает честные веса `Classic 25% / Elite 22% / Royal 19% / Epic 16% / Mythic 11% / Eternal 7%`.
4. Владелица нажимает кнопку в течение 90 секунд. Бот сразу отвечает на callback и убирает кнопку. Затем **сервер** выбирает одну редкость по весам (`secrets.randbelow(100)`) и точно совпадающий ролик с проверкой SHA-256.
5. При поддерживаемом `editMessageMedia` фото заменяется выбранным оригинальным бесшумным MP4 **в том же сообщении**. Подпись пока не раскрывает редкость. Через 12 секунд от подтверждения Telegram API бот **редактирует подпись того же сообщения**: `ВЫПАЛО: <редкость>`. Третьего сообщения с текстом и заглушки карточки нет.
6. Если Telegram **явно вернул HTTP 400** на редактирование фото, один раз используем стабильный запасной `sendAnimation` с тем же MP4; итог редактируется под этим отдельным сообщением. При неясном сетевом сбое, HTTP 401/409/5xx, некорректном ответе — **никаких повтора/дополнительной отправки**, чтобы не дублировать рулетку.

## Ограничения

- MP4 может быть автоматически перекодирован Telegram и зациклен на клиенте. Бот не получает события «анимация воспроизведена до конца»: 12-секундная задержка отсчитывается от ответа Bot API, поэтому на плохой сети клиент может не успеть посмотреть весь ролик к появлению итога.
- Визуальный тест **не выдаёт реальные карты**. Нет начисления, попыток, платежей, DB и фонового сервиса.
- Редактирование сообщения из фото в MP4 следует официальному `editMessageMedia` / `InputMediaAnimation`, но **живую совместимость** нужно подтвердить отдельно; unit-тесты подтверждают лишь формат запросов и безопасность. Режим fallback сохраняет оригинальное фото и добавляет ровно одно сообщение с анимацией.
- Тест не запускается автоматически. Старая команда `/royaltest` всё ещё доступна отдельно в другом workflow; `/wheel` не изменена.
