# Velvet — шесть исходов колеса

Пять новых анимаций: Classic, Elite, Epic, Mythic, Eternal.
Royal включён из уже готового прототипа; его MP4 сохранён без изменений.
Каждый ролик показывает разгон, вращение, замедление и остановку своего сектора
по центру под верхней неподвижной стрелкой. Рамка и рубин остаются на месте,
свечи мерцают, лепестки летят. Цвет результата соответствует выбранному сектору.

## Файлы

- `videos/Classic.mp4`, `Elite.mp4`, `Royal.mp4`, `Epic.mp4`, `Mythic.mp4`,
  `Eternal.mp4` — все шесть отдельных исходов.
- `All_outcomes_preview.mp4` — одновременный просмотр шести роликов.
- `Velvet_all_outcomes.html` — автономный просмотр с выбором исхода и повтором.
- `layers/` — восемь общих слоёв.
- `source/` — движок, шаблон просмотра и скрипты экспорта.
- `checks/` — результаты проверок и финальные кадры.
- `animation_manifest.json` — углы, цвета, длительности и файлы.

Откройте HTML в браузере, выберите исход и нажмите «Крутить». После остановки
нажатие на кнопку повторяет анимацию. При фокусе на колесе работают Enter и
пробел. Все изображения встроены; сервер и интернет не нужны. Во время прохода
выбор исхода заблокирован, повторный старт не создаёт вторую анимацию.

Это визуальные анимации с заданным результатом. В них нет случайного розыгрыша,
списания валюты, выдачи приза или подключения к Telegram.

## Остановки

Координаты исходного диска: 0° — вправо, 90° — вниз, 270° — вверх.
Все остановки рассчитаны на верхний указатель, по центру соответствующего сектора.

| Исход | Центр в исходнике | Полный поворот по часовой | Подсветка |
|---|---:|---:|---|
| Classic | 240° | 1830° | Светло-лиловая |
| Elite | 300° | 2130° | Розово-красная |
| Royal | 0° | 2070° | Золотая |
| Epic | 60° | 2010° | Огненная |
| Mythic | 120° | 1950° | Фиолетовая |
| Eternal | 180° | 1890° | Бирюзовая |

У всех исходов одинаковые длительности и форма разгона/замедления.
Скорость подстраивается под полный угол остановки. Вращение начинается в 0,65 с,
заканчивается в 7,65 с, затем результат удерживается до конца ролика — 10,4 с.
Исходные надписи вращаются вместе с диском. Результат дополнительно показан
горизонтально в заголовке и на кнопке.

MP4: H.264, 720 × 960, 30 кадров/с, без звука.
Обзор: H.264, 720 × 704, 30 кадров/с. Композиция: 1086 × 1448.
Центр диска: (543, 680), радиус: 432.

## Проверки

Все шесть MP4 полностью декодированы. Проверены разрешение, частота кадров,
длительность и SHA-256. Хеш Royal совпадает с предыдущим готовым роликом.
Просмотрены финальные положения всех секторов.

Встроенные скрипты настоящего HTML исполнены в Node.js с нативным Canvas.
Для каждого исхода проверены выбор, старт, правильный верхний сектор,
заголовок и кнопка, удержание результата и повтор. Проверены защита от двойного
старта, Enter/пробел и отказ для неизвестного исхода. Рубин и стрелка проверены
по фиксированным участкам изображения с допуском на полупрозрачность корпуса.

Это проверка скриптов и отрисовки, а не подтверждение совместимости браузеров.
Полная браузерная приёмка остаётся непроверенной: в предыдущем проходе среда
ограничила запуск Chromium, а облачный браузер запретил локальные file-ссылки.
Telegram-подключение и оптимизация под формат стикера — отдельный следующий этап.

## Повторный экспорт

Нужны Node.js, FFmpeg и зависимости package.json. Для совпадения шрифтов
используется Liberation Serif; в HTML предусмотрены Georgia и системный serif.

```sh
npm install
npm run render
npm run verify
```

Команда `render` создаёт пять новых MP4, HTML и финальные кадры.
Royal не пересоздаётся: готовый `videos/Royal.mp4` копируется в каталог экспорта,
если там его ещё нет. Для отдельного исхода:

```sh
node source/render.cjs --outcome Classic
```

По умолчанию экспорт идёт в соседнюю папку `sector_deliverables`.
Её можно задать переменной `VELVET_WHEEL_OUTPUT_DIR`.
Для сборки общего видео после наличия всех шести MP4:

```sh
node source/build_preview.cjs
```

Движок: `source/animation.js`; таблица исходов: `OUTCOMES`;
вызов: `render(ctx, assets, t, { outcome: 'Mythic' })`.
